# 决策 003：优先使用 SEMrush 做研究

## 决策

把 SEMrush API 作为付费搜索策略研究的第一个数据源。

## 考虑选项

- SEMrush API.
- Google Ads Keyword Planner / Google Ads API.
- Ahrefs API.

## 证据

- SEMrush 更适合做竞品付费搜索、广告文案、付费关键词和落地页发现。
- Google Keyword Planner 更适合作为最终关键词量级、出价区间和 forecast 校验来源。
- Ahrefs 对 SEO、SERP 和内容研究有价值，但与第一阶段 SEM 策略问题不如 SEMrush 直接。

## 最终选择

先用 SEMrush。广告正式上线前再加入 Google Keyword Planner 校验。

## 推翻条件

如果 SEMrush 对 Christian、Scripture、prayer、anxiety、anger、stress 等相关关键词簇的付费搜索覆盖不足，再重新评估。
