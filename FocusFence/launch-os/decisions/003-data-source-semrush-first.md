# Decision 003: SEMrush First For Research

## Decision

Use SEMrush API as the first data source for paid-search strategy research.

## Options Considered

- SEMrush API.
- Google Ads Keyword Planner / Google Ads API.
- Ahrefs API.

## Evidence

- SEMrush is better suited to competitor paid-search, ad copy, paid keyword, and landing-page discovery.
- Google Keyword Planner is better as a final validation source for search volume, bid ranges, and forecasts.
- Ahrefs is useful for organic/SERP/content research, but less directly aligned with the first SEM strategy question.

## Final Choice

Start with SEMrush. Add Google Keyword Planner validation before campaign launch.

## Reversal Criteria

Revisit if SEMrush data lacks paid-search coverage for relevant Christian, Scripture, prayer, anxiety, anger, and stress keyword clusters.
